# amd-smi — Decisions Log

> Agent-owned record of *why* significant decisions were made. **Not public docs.**
>
> A decision earns an entry only when **all three** are true:
> 1. **Hard to reverse** — undoing it later is costly.
> 2. **Surprising without context** — a future reader will ask "why this way?"
> 3. **A real trade-off** — genuine alternatives existed; one was chosen for reasons.
>
> If any is missing, don't log it — let the code speak. This is the "why" that code
> comments can't carry because the decision spans many files. Newest entry on top.

## Format

```
## YYYY-MM-DD — <short title>
**Decision:** what was chosen.
**Why:** the forces that made it necessary.
**Alternatives rejected:** what else was considered and why it lost.
**Touches:** files/layers affected (so a future change knows what to reopen).
```
